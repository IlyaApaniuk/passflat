## Risks and what could be cut

- **Risk: no pull at all** (fewer than 5 started cases). The cheapest outcome; it ends the
  deposit hook (H9, H1) with a clear record.
- **Risk: legal** (A14) if E10 starts before the review; mitigated by decision 2.
- **Risk: FR-1 cannot be reproduced in a unit test.** Criterion 7 blocks the task instead of
  guessing; the owner then checks Live Events after any deploy.
- **Risk: season.** December is a low month for moves; a null result is weaker evidence.
- **Cut first if time is short:** FR-5 (reply kit; the owner can write replies), then FR-3
  (guide prompt; guides bring about one relevant click a week). The core of E10 is FR-2, FR-4
  and FR-6; FR-1 matters for every web experiment, not for E10.
