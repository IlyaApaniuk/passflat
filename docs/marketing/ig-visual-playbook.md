# Passflat — IG Visual Playbook (v2)

> Источник: план основателя (см. Приложение A — v1) + критика панелью из 5 экспертных линз (IG-рост 2026 с веб-проверкой, бренд/дизайн, честность/легал, контент-воронка, тулинг), 2026-06-19.
> Аудитория: RU/UA-арендаторы/экспаты в Варшаве. Голос: «бренд с лицом» — честно, чуть бунтарски, на данных.
> KPI: визит → `cost_form_started` (>2% = здорово). Фолловеры — следствие охвата, не цель.

---

## 0. TL;DR — что изменилось в v2 и почему

Твой v1 — **сильная бренд-система, но слабый движок охвата и конверсии**, и он бежит впереди данных. 7 правок по приоритету:

1. **Reels — главный юнит охвата, не статика.** Для аккаунта с ~0 фолловеров статичная картинка — формат с самым низким охватом. Reels дают кратно больше показов не-подписчикам. Статику оставляем как слой профиля/конверсии, но **запуск переякориваем на видео + карусели + collab-посты**.
2. **«OG-карточка = наш визуальный язык» — фактически неверно.** Живая OG-карточка ([src/app/api/og/route.tsx](../../src/app/api/og/route.tsx)) — это 1200×630 ландшафт с сине-индиго градиентом и стеклом, что **противоречит твоему же стоп-листу** (плоско, без градиентов, один акцент). Зелёный сейчас — только цифра. → Либо переякорить план на реальный шильд, либо обновить роут. Рекомендация ниже.
3. **Холодный старт данных — severe, не «тонко».** Продукт прячет статистику до `reliableMin:5` отчётов на район ([src/lib/cost-stats.ts](../../src/lib/cost-stats.ts)). 18 районов → ~90 отчётов до первой честной районной цифры. **Пиллар «Платформа» (40%) нечем наполнить честно в день 1.** Нужен cold-start-контент (город-агрегат + «помоги собрать»).
4. **Честность/легал: план срывает защиты, которые продукт уже соблюдает.** Медиана **намеренно смешивает скрейп Otodom (цены объявлений) с реальными отчётами** → «ниже рынка» на публичной карточке — это over-claim. Нужны: гейт N≥5, обязательные N+дата на карточке, формулировка «медиана района по отчётам» вместо «рынка», дефамационное правило для мемов, расширенный стоп-лист.
5. **Нет CTA и измерения.** В ленте IG ссылки не кликаются — а в плане нет link-in-bio / Stories-link / DM-кейворда. И `ref=ig_ad` сейчас атрибутирует только **регистрации** ([src/lib/referral.ts](../../src/lib/referral.ts)), а не анонимный `cost_form_started` — то есть твою же метрику он не измерит.
6. **Шрифты и цвета — по факту из кода.** Шрифт не «Inter/Manrope», а **Manrope + JetBrains Mono** ([src/app/[locale]/layout.tsx](../../src/app/[locale]/layout.tsx)); моно — идеальный для гигантской цифры. Синий **#0036ff не проходит контраст** на тёмном (2.53:1, фейл WCAG) — убрать как текст; реальный синий продукта #3b82f6, только декоративно. Зелёный #8bde54 на #0f172a = 10.77:1 (AAA, отлично).
7. **Тулинг: не пересобирай карточку руками в Canva.** Роут `/api/og` **уже рендерит** её из реальных медиан (`rollUpDistricts`, [src/lib/cost-aggregates.ts](../../src/lib/cost-aggregates.ts)). Высший рычаг — генерить картинки из роута (добавить 4:5 + скрипт), а не Brandfetch→Canva→Recraft. Recraft — вон из v1.

**Что оставляем без изменений (валидировано):** инстинкт «бренд уже есть, генераторы не нужны»; дисциплина одного зелёного акцента (AAA); система пилларов + ротация; стоп-лист честности (расширить, не ослаблять); модель «дублируй один шаблон»; KPI = form-starts.

## 1. Стратегия (исправлено): охват ≠ конверсия

Две разные задачи, не путать:

- **Охват/дискавери** (привести новых): **Reels + collab-посты + caption-SEO.** Это то, чего в v1 не было совсем.
- **Конверсия профиля** (кто уже зашёл): сетка, зелёная нить, saveable-карточки. Это v1 и делал — но это второй этап, не первый.

При ~0 фолловеров **сетку почти никто не видит как сетку** — её увидит тот, кто уже зашёл в профиль. Поэтому перфекционизм по «рядам из 3» — преждевременная оптимизация. Сначала охват, потом грид-эстетика.

**Связь с Threads:** один инсайт = 3 поста. Дневная цифра → текстовый хук в Threads (там ссылки кликаются) → Reel/карусель в IG → Stories. Меряем путь thread-показ → визит профиля → `cost_form_started`, а не лайки.

## 2. Бренд-система (исправлено по коду)

**Палитра (Canva Brand Kit):** фон `#0f172a`, карточка `#1e293b`, акцент-зелёный `#8bde54` (цифра/акцент, AAA), текст `#f8fafc`, приглушённый `#94a3b8`. Синий — **только** реальный `#3b82f6` и **только декоративно** (шильд логотипа, тонкая не-текстовая деталь), никогда как текст/цифра. **`#0036ff` выкинуть** — нечитаем на тёмном.

> Правило в кит: «синий — декор, не текст. Любой текст ≥4.5:1 к фону. Зелёный — не на зелёном глоу, не на светлом оверлее.»

**Шрифты:** **Manrope** (заголовки/UI) + **JetBrains Mono** (цифра-герой, табличные знаки). Моно держит гигантскую цифру от «прыжков» между постами и даёт «терминал/чек»-авторитет под голос бренда. Источник правды по шрифтам — **код, не Brandfetch**.

**Глубина:** НЕ «плоско без градиентов» (это противоречило шипнутому бренду). Разрешено: фон-градиент `135deg #0f172a→#1e293b` + один радиальный акцент-глоу за цифрой (оба уже есть в продукте). Запрещено: тень на тексте, многоцветные градиенты. Так IG = сайт = OG-превью.

**Форматы (вместо одного 4:5):**

- **Reel 9:16 (1080×1920) — основной охватный юнит.** «Мем» и «reveal» (размытая цифра → заполняется бар «ты vs медиана») — это нативно Reels.
- **Карусель 4:5 (1080×1350) — saveable-юнит.** Слайд 1 = хук/цифра, 2–4 = разбор/чеклист, последний = мягкий CTA. Никогда не одиночная статика там, где можно карусель.
- **Одиночная статика — редко.**
- **Crop-safe:** цифра-герой и район — внутри центрального 1080×1080 (грид режет 4:5 в квадрат). N/лого/дата — в крайние полосы. Иначе зелёная нить выпадает из превью грида.
- **Авто-фит цифры:** max ~220px / min ~120px (всё ещё «герой»), shrink-to-fit по ширине, «zł»/«%» ~45% от размера цифры. Зафиксировать высоту зоны цифры, чтобы бар не прыгал. Протестировать худшее: `≈4 199 zł`, `−27%`, `≈12 500 zł`.
- **Длинные районы:** `Praga-Południe`, `Śródmieście`, `Białołęka` + диакритика. Футер — авто-лейаут, район отдельной строкой, под нужный максимум; лейблы под самую длинную локаль (UA «медіана району» vs RU «медиана района»), лево-выключка, чтобы RU/UA-разница переносилась вниз, не в цифру.

## 3. Контент-пиллары (перевзвешены) + cold-start

В v1 «Платформа» = 40%, но при холодном старте её **нечем наполнить честно**. Добавляем пятый пиллар и меняем веса:

| Пиллар          | Вес                          | Что                                                                           | Формат              |
| --------------- | ---------------------------- | ----------------------------------------------------------------------------- | ------------------- |
| **CTA/Просьба** | 15–20%                       | «Сколько ты реально платишь? Добавь за 60 сек → ссылка в шапке» + скрин формы | статика/Stories     |
| Платформа       | ~25% (растёт по мере данных) | цифра-герой + бар, **только район с N≥5**                                     | карусель/Reel-cover |
| Польза          | ~20%                         | чеклист (зелёные галочки) — например твой Day-3                               | карусель            |
| Данные          | ~20%                         | мини-таблица районов; «осталось N отчётов до медианы по Мокотову»             | карусель/Reel       |
| Мем             | ~20%                         | панчлайн, акцент-слово зелёным; **бьём по системе, не по имени**              | Reel                |

**Cold-start лестница (недели 1–4), пока данных мало:**

1. **Город-агрегат** (Warszawa в целом набирает N≥5 быстрее любого района) — первые честные цифры берём отсюда.
2. **«Мы пока не знаем — помоги собрать»** — честный мем-формат, превращает дыру в данных в контент.
3. **Скрины формы / UI**, founder-POV («почему я это делаю»).
4. **Переиспользовать `/costs/share`** — личные «brag»-карточки ([src/app/[locale]/[city]/costs/share](../../src/app/[locale]/[city]/costs/share)) уже несут `?ref` и сделаны как вирал-юнит.
5. Район → в пиллар «Платформа» **только когда его `reportsCount ≥ 5`. Прогресс района — повторяющийся пост «Данные».**

## 4. Честность и легал (обязательно — это твой moat)

**Гейт N≥5 на любую %-сравнительную карточку.** N=1–4 → НЕ публикуем «% ниже/выше», только нейтральная «что сообщают в {районе}» (как уже делает `share/page.tsx`). Гейт встроить в чек-лист публикации, чтобы его нельзя было пропустить «поменяв только цифру».

**N и дата — обязательны НА карточке**, не опционально: футер `район · N отчётов · данные на MM.YYYY`. Статичная картинка переживает данные на годы — без N+даты это ложная точность и ложная вечность.

**Формулировка:** убрать «ниже рынка / below market» (это юридический comparative claim + смешанная со скрейпом медиана). Использовать продуктовую рамку: **«ниже медианы района по отчётам Passflat»**, а внутри p25–p75 — бейдж **«в пределах района»**, не форсить вердикт. Любой below/above % — только на карточках, нормализованных **per-m² или по типу квартиры** (бар «ты vs медиана» иначе сравнивает студию со всеми квартирами района — apples-to-oranges).

**Скрейп-вопрос для публичных карточек:** медиана смешивает `source='scraped'` (цены объявлений) с отчётами. Либо (a) для публичной карточки считать % только по user-отчётам, либо (b) оставить смесь, но словить как **«по объявлениям и отчётам»**, а не «рынок». Нельзя молча вещать медиану на ценах объявлений как «сколько платит рынок».

**Мемы — дефамация:** бьём ВВЕРХ по системе/категории («rynek», «риелторы вообще», «czynsz как чёрный ящик»), **никогда по именованному** агентству/арендодателю/зданию/человеку. Никаких фактических утверждений + цифры на конкретного. Мнение/пародия — да.

**Расширенный СТОП-ЛИСТ** (к существующему добавить):

- старое (оставить дословно): светлый фон; >1 акцента; «verified / проверено жильцами»; выдуманная статистика; разные шрифты; стоковые риелторы.
- ➕ никакого намёка на официальный/гос-источник или «официальную статистику»;
- ➕ никакой фейк-срочности («единственный источник», «успей до подорожания»);
- ➕ никаких вводящих в заблуждение before/after;
- ➕ никаких абсолютных превосходных без данных («самый дешёвый район»);
- ➕ забанить ВСЕ синонимы «verified/точно/гарантированно» («подтверждено», «точные данные», «official»), не только одну фразу;
- ➕ не называть идентифицируемого арендодателя/агентство/здание в утверждении;
- ➕ ни одной сравнительной карточки ниже порога N.

**Методология — один раз на аккаунт:** закреплённый highlight / ссылка в шапке «как мы считаем» (медиана, N, источники вкл. объявления, свежесть). Карточки остаются чистыми, но каждая claim в один тап от своих оговорок.

**Пре-публиш чеклист (вшить в описание Canva-шаблона):**
`[ ] N≥5 для любого %-сравнения (иначе нейтральная карточка)` · `[ ] N + «данные на MM.YYYY» на карточке` · `[ ] формулировка «медиана района по отчётам», не «рынок» (или per-m²/тип)` · `[ ] не назван арендодатель/агентство/здание` · `[ ] есть следующий шаг + ref-ссылка, до которой аудитория дотянется`

## 5. Дискавери и дистрибуция (которых не было в v1)

- **Searchable NAME аккаунта** — буквальные поисковые слова: `Аренда Варшава · реальные цены`.
- **Caption-SEO:** первая строка подписи — естественный запрос («Сколько стоит снять однушку на Мокотове?»).
- **Alt-text** на каждой карточке — данные словами (индексируется поиском).
- **Озвучка в Reels:** проговаривать бренд + район + цифру (транскрипция индексируется).
- **Хэштеги:** 3–5 гипер-узких (`#арендаваршава #mieszkaniewarszawa`), никаких широких. В 2026 они лишь контекст-хелперы.
- **Collab-посты — главный рычаг при ~0 фолловеров** (нет порога подписчиков, публикуется в обе аудитории): соавторь «Данные»-посты по районам с экспат/релок/RU-UA-сообществами Варшавы, локальными tenant-страницами, релок-блогерами. **В v1 этого не было совсем — добавить как лидер первых 30 дней.**

## 6. CTA и измерение (блокирующий слой, не «опция Step 5»)

- **Link-in-bio** на один ref'ный URL: `passflat.com/ru/warsaw/costs/submit?ref=ig_bio` (валидно для `sanitizeRef`).
- **Stories** с нативным link-стикером (доступен всем) → `?ref=ig_story`.
- **DM-кейворд луп:** «напиши ЦЕНА в комменты → пришлю ссылку/медиану твоего района» — главный мост лента→сайт, раз ссылок в ленте нет.
- **Разные ref на поверхность:** `ig_bio / ig_story / ig_dm / ig_reel` — чтобы сравнивать каналы.
- ⚠️ **Дыра в атрибуции:** `?ref=` сейчас попадает в БД только при регистрации (`Profile.referredBy`), а `cost_form_started` — анонимный и часто без регистрации. Чтобы мерить **именно** воронку из KPI, нужно зарегистрировать `ref` как PostHog **super-property** на первом визите (см. §8). Иначе IG→form-start невидим. (UTM-стиль `?utm_source=` этот код НЕ читает — используем `?ref=`.)

## 7. Тулинг и процесс (исправлено для соло-фаундера)

- **Высший рычаг — генерить карточки из существующего `/api/og`**, а не пересобирать в Canva. Роут уже принимает `?title=&subtitle=&stat=&statLabel=&split=` и рисует тёмную карточку с зелёной цифрой из реальных медиан. → добавить 4:5-вариант + крошечный `scripts/gen-cards.ts`, который гоняет `rollUpDistricts()` и пишет PNG-пачку. **Одна команда = пачка он-бренд карточек с реальными цифрами, без ручного копирования (= без типо-риска и нарушения честности).**
- **Recraft — вон из v1** (лишний инструмент при 13 показах, риск дрейфа стиля).
- **Canva Brand Kit — оставить, но только для не-датовых пилларов** (Мем/Польза). Magic Design недетерминирован — не для карточки, где нужны точный HEX/шрифт/медиана.
- **Brandfetch (Шаг 1)** — ок для лого/фавикона/HEX, но **шрифты бери из кода**, не из Brandfetch.
- **Батч + расписание:** одна 90-мин сессия/мес → 12 карточек скриптом → подписи в один Google Sheet (дата, район, снимок медианы, N, пиллар) → массовый автопостинг в **Meta Business Suite** (бесплатно, нативно). Sheet = и календарь, и версионирование, и журнал свежести. Later/Buffer не нужны.
- **Имя файла = самоописание:** `{район}_{пиллар}_{ГГГГММДД}_n{кол-во}.png` (напр. `mokotow_platforma_20260619_n14.png`).

## 8. Код-рычаги (опционально, требуют твоего «го» — это правки продукта)

Не для маркетинг-папки, но дают самый большой рычаг. Делать на ветке, локально, без прод-миграций без апрува:

1. **4:5-вариант OG-роута + `scripts/gen-cards.ts`** — превращает генерацию карточек в одну команду из реального источника. ⭐ highest-leverage.
2. **`ref` как PostHog super-property** ([posthog-provider](../../src/lib) + чтение `pf_ref`/`window.location`, `register_once({ ref })`) — чтобы анонимный `cost_form_started` ломался по каналам. Без этого IG-метрика, которую ты хочешь, не считается.
3. **Сверить стиль OG-роута** с этим плейбуком (убрать сине-индиго градиент лого/стекло ИЛИ принять их как бренд) — один источник правды до генерации 12 постов.

---

## 9. Следующий шаг

Изначально планировалось: «Canva-спека герой-шаблона по слайдам/слоям + первые 9 постов сетки ×RU/UA».
**Переформулировано под cold-start:** первые 9 — это НЕ дата-браги (данных нет), а **cold-start лестница** (§3): город-агрегат + «помоги собрать» + founder-POV + Польза-чеклист, в формате Reel/карусель, с CTA-слоем и ref-ссылками. Дата-браги по районам включаются по мере `N≥5`.

## Приложение A — План основателя (v1, дословно, как источник)

```
== ЗАПУСК IG-ВИЗУАЛА: КОНКРЕТНЫЕ ШАГИ ПО ПОРЯДКУ ==
Инсайт: генераторы бренд-буков НЕ нужны — бренд уже есть (цвета + OG-карточка сравнения = визуальный язык).
ШАГ 1 — Brandfetch (5 мин): логотип (SVG+PNG), точные HEX (#0f172a / #8bde54 / #0036ff), реальные шрифты сайта (вероятно Inter/Manrope), фавикон.
ШАГ 2 — Canva Brand Kit (15 мин): логотип, 3 бренд-цвета + нейтрали (текст #f8fafc, приглушённый #94a3b8, карточка #1e293b), шрифты из Шага 1. Magic Design под кит.
```
