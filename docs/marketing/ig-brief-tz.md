# Passflat — ТЗ на запуск Instagram (для подрядчика)

> Самодостаточный бриф. Исполнитель (SMM + дизайнер/монтажёр) может выполнить без доуточнений.
> Стратегия-первоисточник: `docs/marketing/ig-visual-playbook.md`. Этот файл — операционное ТЗ с готовыми текстами.

---

## 1. Контекст и цель

**Passflat** — платформа прозрачности аренды в Варшаве. Показывает, сколько арендаторы **реально платят** (аренда + komunalka), медианы по районам — **по отчётам жильцов, а не по ценам объявлений**. Это НЕ доска объявлений и НЕ поиск квартир.

- **Аудитория:** арендаторы/экспаты Варшавы, RU/UA-первые (плюс PL/EN). Молодые, снимают или ищут жильё.
- **Голос бренда:** «свой парень» — честно, по делу, чуть бунтарски, на данных. RU — ты-форма.
- **Цель IG:** верх воронки → визиты на сайт → **`cost_form_started`** (человек добавляет свои расходы). Подписчики — следствие охвата, не цель.
- **Сайт-CTA:** `passflat.com/ru/warsaw/costs` (для UA-аудитории `/uk/`). Ссылка кликается только в шапке профиля и в Stories (в ленте ссылок нет).

## 2. ЖЁСТКИЕ ПРАВИЛА (исполнителю соблюдать строго)

**Честность (нарушение = удар по бренду):**

- ❌ НИКОГДА «verified / проверено / подтверждено» про объявления или арендодателей.
- ❌ НИКОГДА выдуманных цифр. Все числа — только из реальных данных, которые даёт основатель.
- ❌ Не называть медиану «рынком/рынок» — только «по отчётам жильцов / сколько реально платят».
- ✅ Цифру по району публикуем только если по нему **≥5 отчётов** (основатель подтверждает). Иначе — без конкретной цифры.
- ✅ На дата-карточках обязателен футер: `по отчётам жильцов · ММ.ГГГГ`.

**Позиционирование:**

- ❌ Не подавать Passflat как «поиск квартир / маркетплейс объявлений / разместить объявление». Это роль конкурентов.
- ✅ Passflat = проверка реальной цены района ПЕРЕД подписанием + вклад своих расходов.

**Формат и продакшн:**

- ❌ Основатель НЕ снимается на камеру. Никаких говорящих голов, никаких стоковых «риелторов с ключами».
- ✅ Reels делаются из: **анимированного текста**, **записи экрана** продукта, **бесплатного сток-видео** Варшавы (Pexels/Pixabay) + текст. Подробно — раздел 6.

## 3. Визуальный стиль

**Палитра (Canva Brand Kit):**

- Фон: `#0f172a` (тёмный navy) — на ВСЕХ тайлах.
- Карточка/блок: `#1e293b`.
- Акцент (один на тайл): зелёный `#8bde54` — цифра / ключевое слово / галочки / стрелка.
- Текст: `#f8fafc`. Приглушённый: `#94a3b8`.
- ❌ Синий `#0036ff` НЕ использовать (не читается на тёмном). Если нужен синий — только `#3b82f6` и только декоративно, не текст.

**Шрифты:** Manrope (заголовки/текст) + **JetBrains Mono** (все цифры — табличные, не «прыгают»).

**Глубина:** допустим лёгкий фон-градиент `135° #0f172a→#1e293b` + один мягкий зелёный радиальный глоу за фокусом. ❌ Тени на тексте и многоцветные градиенты — нельзя.

**Принцип тайла:** тёмный фон, много воздуха, ОДИН крупный фокус (цифра/слово), читается в превью-миниатюре. Один зелёный акцент на тайл — он создаёт «зелёную нить» по сетке.

**Форматы:**

- Reel: 9:16, 1080×1920.
- Карусель: 4:5, 1080×1350. Crop-safe: ключевой элемент держать в центральном квадрате 1080×1080 (грид режет 4:5 в квадрат), лого/футер — в крайние полосы.
- Цифра-герой: авто-фит (макс ~220px, мин ~120px), «zł»/«%» ~45% от размера числа.

**Активы от основателя:** логотип (SVG+PNG), фавикон, точные HEX (выше), доступ к live-данным по районам.

## 4. Компоновка профиля

**Имя (поисковое):** `Аренда Варшава · реальные цены`
**Bio:** «Сколько реально платят за аренду по районам Варшавы — по отчётам жильцов, а не из объявлений. Проверь свой 👇»
**Ссылка в шапке:** `https://passflat.com/ru/warsaw/costs/submit?ref=ig_bio`
**Highlight (закреп):** «Как считаем» — 2–3 Stories: что такое медиана, что данные от жильцов (вкл. часть из объявлений), свежесть.

**Сетка первого экрана (3×3, ротация рубрик, зелёная нить):**

```
┌──────────────┬──────────────┬──────────────┐
│ 1 REEL       │ 2 CAROUSEL   │ 3 REEL       │
│ founder      │ польза       │ провокация   │
│ «переплатил» │ 5 проверок   │ 3000→3800    │
├──────────────┼──────────────┼──────────────┤

│ продукт      │ данные       │ CTA          │
│ screen-rec   │ цены районов │ «добавь 60с» │
├──────────────┼──────────────┼──────────────┤
│ 7 REEL       │ 8 CAROUSEL   │ 9 REEL       │
```

## 5. Контент-план — 9 постов с готовыми текстами

Состав: ~5 Reels + 3 карусели + 1 статика. Темп: ~1 пост / 1–2 дня (9 за ~2 недели). Stories — ежедневно (репост Reels + опросы + закулисье). На каждом посте: первая строка подписи = поисковый запрос; 3–5 узких хэштегов; CTA «ссылка в шапке».

Базовый набор хэштегов (выбирать 3–5): `#арендаваршава #варшава #mieszkaniewarszawa #wynajemwarszawa #варшаваквартира #переездвпольшу`

### Пост 1 · Reel (анимированный текст) · founder-голос

**Визуал:** тёмный фон, белый текст по центру (Manrope), по одной строке с fade. Аудио: спокойный трендовый.
**Сцены:**

- 0–2с: `Снял первую квартиру в Варшаве. Переплатил.` ← «Переплатил» зелёным

- 11–13с (CTA-кадр): `Проверь свой → ссылка в шапке` + логотип

## 6. Производство Reels «без камеры» (3 формата)

- **A. Анимированный текст** (посты 1, 3, 7, 9) — CapCut (бесплатно): тёмный фон → текстовые блоки с fade/typewriter → трендовое аудио → экспорт 9:16. Без камеры/голоса.
- **B. Запись экрана** (пост 4) — записать экран сайта (QuickTime/мобильная запись) → в CapCut подписи + музыка. Без лица.
- **C. Сток + текст** (опц. для провокаций) — бесплатное вертикальное видео Варшавы (Pexels/Pixabay) + крупный текст. Без съёмки.

Инструменты: **CapCut** (Reels), **Canva** (карточки/карусели, Brand Kit), бесплатный сток. **Recraft/генераторы бренд-буков не нужны** — бренд задан этим ТЗ.

## 7. Реклама (Meta Ads: Instagram + Facebook)

**Что запускать:** НЕ рекламировать вслепую с первого дня. Сначала выложить 5–6 Reels органически (1–2 недели), посмотреть, какой собрал больше сохранений/охвата → **на победителя** ставить рекламу. Лучшие кандидаты по хуку: Пост 3 (komunalka) или Пост 9 (ASK vs PAY) или Пост 5 (данные).

**Настройки теста:**

- Цель: **Traffic** (трафик на сайт), без пикселя на старте.
- Ссылка объявления: `https://passflat.com/ru/warsaw/costs?ref=ig_ad` (для UA-аудитории — `/uk/...?ref=ig_ad`).
- Гео: Варшава + 30 км. Возраст: 22–40. Языки/интересы: аренда жилья, переезд в Польшу, экспаты, украино-/русскоязычная аудитория.
- Плейсменты: Reels + Stories + Feed (можно Advantage+ placements).
- Креатив: вертикальный Reel-победитель + короткий текст-хук.

**Бюджет (поэтапно):**

- **Тест:** €5–8/день × 5–7 дней на 1 (макс 2) креатив = **~€35–60**. Не дробить на 5 кампаний по €5 — дать Meta оптимизировать на одной.
- **Решение по данным:** через 5–7 дней основатель смотрит PostHog → воронка «визит→отчёт» → **Breakdown по `ref` = `ig_ad`**.
  - Конвертит (визит→`cost_form_started` есть) → масштаб креатива до **€15–20/день**.
  - Ноль конверсии → пауза, менять креатив/оффер, НЕ лить дальше.

**Важно:** атрибуция уже настроена — `ref` пишется как PostHog super-property, так что `ref=ig_ad` виден в воронке по конверсиям, а не только по кликам.

## 8. Метрики и отчётность

**Исполнитель отчитывается раз в неделю:** охват, сохранения, заходы в профиль, клики по ссылке в шапке/Stories, прирост по постам (какой формат/рубрика лучше).
**Основатель смотрит сам (PostHog):** воронка «визит → `cost_form_started`», Breakdown по `ref` (`ig_bio` / `ig_story` / `ig_ad`) — какой IG-канал реально даёт отчёты, а не только клики. Это и есть KPI.

## 9. Объём работ исполнителя (scope)

1. Настройка профиля (имя, био, ссылка `?ref=ig_bio`, highlight «как считаем»).
